# EVA Risk Desk

Многостраничный исследовательский сервис для анализа внешней обстановки на траектории МКС, накопления собственного архива наблюдений и проверки прогнозов.

## Что работает

- отдельные страницы: обзор, признаки, МКС, прогноз/факт, архив, источники;
- текущее положение МКС из Where The ISS At;
- орбитальные элементы МКС (NORAD 25544) из CelesTrak;
- интегральный поток протонов NOAA GOES;
- raw-архив каждого успешного ответа с UTC-временем и SHA-256;
- постоянный репозиторный архив через GitHub Actions в `site/data/raw/`;
- локальный архив текущего браузера через IndexedDB;
- экспорт локального архива в JSON;
- собственный baseline-прогноз SEP на +60 минут и последующее сопоставление с фактом;
- исторический разбор SEP по произвольной дате 01.05–30.06.2024 через NASA DONKI.

## Временная честность

Исторический разбор и строгий forecast replay не смешиваются. Для строгого replay нужны версии источников, которые были опубликованы к моменту информационного отсечения. Современная орбита не используется как историческая.

## Автоматический сбор

Workflow `.github/workflows/collect-data.yml` раз в час получает публичные источники и записывает настоящие JSON-файлы:

```
site/data/raw/YYYY/MM/DD/
  iss_position_*.json
  iss_omm_*.json
  goes_integral_protons_*.json
```

Индекс файлов хранится в `site/data/archive-index.json`.

## Публикация

GitHub Pages публикует каталог `site/`. После merge в `main` workflow публикации обновит сайт автоматически.

## Ограничение интерпретации

GOES — proxy внешней среды, а не индивидуальная доза космонавта. Сервис предназначен для исследовательской поддержки решения и не является системой допуска к ВКД.
