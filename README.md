# EVA Risk Desk

Интерактивный демонстрационный интерфейс для сравнения окон ВКД: временной ползунок, положение МКС, свет и тень, SEP, потенциальные сближения и оценка риска.

## Публикация

Сайт автоматически публикуется через GitHub Pages из каталога `site/`.

> В прототипе используются демонстрационные данные. Он не предназначен для оперативного принятия решений.
